Modeling the spread of a pandemic using ordinary differential equations (ODEs) and Python. 
The project implements an ODE-based version of the SEIR (Susceptible–Exposed–Infectious–Recovered) epidemiological
model used by the Norwegian Institute of Public Health (FHI), utilizing numerical ODE solvers based on the methods 
described in [Solving ODEs in Python](https://sundnes.github.io/solving_odes_in_python/).
